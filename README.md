# Pomodoro Focus Timer

Pomodoro Focus Timer alternates work sessions and breaks so a task has a clear beginning and end.

## Interface

The page centers a circular countdown with Focus, Short break, and Long break modes. Timer lengths, a session count, and a focus-task list sit alongside it.

## Features and use

Choose a timer mode, start or pause the countdown, reset the current mode, or skip to the next mode. Edit the focus and break lengths in minutes. Add focus tasks and check them off. Completed focus sessions increase the session count.

## Data and limits

Timer lengths, completed session count, and the focus list are saved in localStorage. The active countdown resets after a page reload. There are no alarms or browser notifications.

## Run locally

Use Node.js and npm, then run these commands from the project folder:

```sh
npm install
npm run dev
```

The app is built with React and Vite. Check the source and production build with:

```sh
npm run lint
npm run build
```

## Deployment

The public app is published with GitHub Pages at [https://a2rp.github.io/pomodoro-focus-timer/](https://a2rp.github.io/pomodoro-focus-timer/). To build and publish the current version, run:

```sh
npm run deploy
```
